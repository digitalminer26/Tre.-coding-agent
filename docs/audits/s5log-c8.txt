**Q2 (wire format):**
- **(a) Raw newlines:** `JSON.stringify` escapes `\n` and `\r` inside strings and emits no raw whitespace outside them, so writer output never contains a raw newline. `split("\n")` round-trips every accepted line. U+2028/2029 are not split points. No finding.
- **(b) BOM:** A BOM at file start and a BOM mid-file both fail `lineIsValid` and are classified as corruption (S5LogCorruptionError on a pass, `corruptLines` on replay). A BOM'd tail is classified partial. This is consistent and documented. No finding.
- **(c) CRLF:** A CRLF-terminated mid-file line is corrupt, as the header promises. But a **tail** of `{...}\r` with no `\n` fails `lineIsValid` because it ends in `\r`, so it is classified **partial** and truncated by the next append. The same JSON without the `\r` would be kept as V-g2. The header says CRLF lines are refused as non-canonical; here a fully parseable record is silently discarded and no corruption is reported.

**Q3 (replay vs appendUnit divergence):** Excluded. Both paths use the same `provenThrough` watermark and the same `reliedBytes` computation. Replay's second `buildPrefix` uses the post-sync watermark, and a failed replay sync leaves the watermark unmoved, so a later `appendUnit` on the same instance sees the same label. The `provenOn` update is only reached when the sync succeeds. No same-instance label contradiction is reachable.

**Findings:**
1. **Test `c5-Q1` does not localize to the digest guard (Q1).** Scenario: rm+recreate yields a different inode, so `identityOfPath` throws before `assertSnapshotIntact` reaches the digest. Deleting the digest comparison leaves the test green. Fix: force the same inode number (or assert via a stub of `identityOfPath`) so the digest is the only refusing gate.
2. **Tail `\r` complete record is silently truncated (Q2c).** Scenario: file ends with `{"id":"x","kind":"k"}\r` (no `\n`). `readState` marks it partial, `replay()` excludes it with no `corruptLines` entry, and `append()` ftruncates it away. Expected per header: refused as non-canonical, not discarded. Fix: classify a tail ending in `\r` as corrupt (or refuse at (c0)) rather than partial, and add a test that asserts refusal.
