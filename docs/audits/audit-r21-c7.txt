## Finding

1. **LOW — Indented code on a list-marker line is not tracked**

   Appended to the valid base document:

   ```markdown
   # Probe

   -     x
         §99999
         y
   ```

   **Expected:** The five spaces after `-` make the item’s content column 2. The four remaining spaces start an indented code block; the following six-space lines continue it. `§99999` is code and should be exempt.

   **Executed repro:**

   ```text
   $ node scripts/contract-check.mjs docs/audits/probes-r21-c7/codehead.md
   exit 1
   stderr: contract-check: FAIL C9 ... — line 6006: §99999
   ```

   **Minimal fix:** When a list marker has more than four columns of padding and its first content begins an indented code block, initialize the indented-code state on that marker line, with the continuation floor at the item content column plus four.
