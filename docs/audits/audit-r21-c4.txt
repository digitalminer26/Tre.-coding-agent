## 1. LOW — Ref after a same-line type-2 HTML-block closer is flagged

**Fixture:** `docs/audits/probes-r21-c4/same.md`, consisting of the valid base document followed by:

```markdown
<!-- ok --> §99999

end
```

**Expected:** CommonMark parses the entire first line as a type-2 raw HTML block. Under C9’s stated raw-HTML-block masking model, the ref is masked.

**Actual:**

```text
$ node scripts/contract-check.mjs docs/audits/probes-r21-c4/same.md
exit 1
contract-check: FAIL C9 every body §ref resolves ... — line 6003: §99999
```

The checker masks only through `-->` and scans the rest of the line as prose. This is overstrict, not laundering. The implementation explicitly describes this behavior in the closed-comment branch.

**Minimal fix:** When a closed comment starts a type-2 HTML block, mask the remainder of that physical line as part of the HTML block. Preserve the current continuation scan for inline comments.
